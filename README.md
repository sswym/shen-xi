# shen-xi · 沈栖

一个有自己日子的陪伴角色，跑在 DeepSeek Harness 里，通过 **QQ 官方机器人 API** 和主人说话。

她不是客服，也不是一个换皮的聊天窗口：她有自己的作息、天气、每天遇到的小事、心情、精力、对主人的好感度，以及一本慢慢变厚的记忆。到点时她会自己判断要不要在 QQ 上找你；不想说话就不说。

**她只活在 QQ 私聊里。** QQ 对话现在存进一个专用 DSH Session：侧边栏能看到、能改名、删除、归档。插件不改其他 Web 会话的提示词或历史，也不把 QQ 聊天混进 Web 对话的上下文。

## 她有什么

| 能力 | 说明 |
|---|---|
| 人格 | `soul.md` 是一整份人物设定：性子、说话方式、底线、日子。可在 DSH 界面里直接改。 |
| 生活 | 每天按日期确定性地生成 0–5 件小事（猫、旧书、菜市场、天气、邻居），并推导“此刻在做什么”。同一天永远一致。 |
| 心情 / 精力 | 心情 −2 到 2，精力 0–100；会随聊天、事件和作息变化。 |
| 好感度 | 0–100，分「陌生 / 眼熟 / 朋友 / 亲近 / 很重要 / 离不开」六级；聊天和主动消息会慢慢加，每天有上限。 |
| 记忆 | 关于你的事实、偏好、约定、重要事件；聊天后自动提取，也能手动加、搜、删。 |
| 主动消息 | 每天若干次“心跳”，她看当下心情、今天遇到的事和你们最近聊过什么，决定要不要发一条 QQ。 |
| 分享趣事 | 主动消息只挑**已经发生**、今天还没跟你讲过的事，用她自己的话说，不照念事件描述。 |
| QQ 收发 | 官方 API v2：AppID/AppSecret 换 token，WebSocket 网关收 C2C 私聊，`/v2/users/{openid}/messages` 发文本。 |
| 被动回复 | 收到你的消息时带事件 `msg_id` + 递增 `msg_seq` 回复，走 5 分钟被动回复窗口，不消耗主动消息额度。 |
| 分条气泡 | 生成内容用换行分段，发送时拆成多个独立 QQ 消息气泡（最多 4 段；长段落再按长度切）。 |
| DSH 界面 | 设置 → 陪伴：概览、记忆、维护、生活、设置五个页签；也能在概览里直接和她聊。 |
| 会话存储 | QQ 对话写入一个专用 DSH Session（侧边栏显示「陪伴 · 沈栖（QQ）」）；可改名、删除、归档，插件在会话不可用时会自动新建。 |

## 安装

```sh
git clone https://github.com/sswym/shen-xi.git
dsh plugin --profile web add ./shen-xi
systemctl --user restart dsh-web.service   # 或者让 profile 的 HMR 热加载
```

刷新 DSH Web，在 **设置 → 陪伴** 看到她。插件只依赖宿主提供的 `llm`、`timer`、`webServer` 服务，没有第三方运行时依赖。

## 接 QQ 官方机器人

1. 在 [QQ 开放平台](https://bot.q.qq.com/) 创建机器人，拿到 **AppID** 和 **AppSecret**。
2. 在 QQ 里把机器人加为好友（官方 API 只能给有会话关系的用户发私聊）。
3. 打开 **设置 → 陪伴 → 设置 → QQ**，接入方式选 **QQ 官方 API**，填 AppID / AppSecret，保存。
4. 打开「启用 QQ」，再点「测试连接」。成功会显示机器人昵称。
5. **绑定主人**：设置页会显示一个 6 位绑定码。用你的 QQ 私聊机器人，直接发送这 6 位数字（前后可以有空白，但不能夹在别的话里）：

   ```text
   123456
   ```

   发对码的 OpenID 会被记成主人，绑定码立即轮换；之后只接受这个 OpenID 的私聊，主动消息也只发给他。

> 官方 API 的 `user_openid` 不是 QQ 号，也不能反查 QQ 号。绑定码就是用来把“你的 OpenID”安全地交给插件的。
>
> 一次发言拆成两个气泡时，平台按两条消息计频控；`maxPerDay` 统计的是“发言次数”，不是气泡个数。

### 主动消息频控

不带 `msg_id` 的消息是主动消息，受 QQ 开放平台频控；不同机器人权限不同，失败时错误会显示在界面和 `lastError` 里。默认每天最多 6 条、最小间隔 90 分钟、23:30–08:00 静默；发送失败时先把心跳频率调低。

## OneBot / NapCat（兼容模式）

如果不想用官方 API，可以在设置里切到 **OneBot 11 / NapCat**：

- 本机运行 NapCat，开 HTTP 3000 与正向 WS 3001；
- 填 HTTP、WebSocket、Access Token 和主人 QQ 号；
- 只处理这个 QQ 号的私聊。

OneBot 模式没有官方 OpenID 绑定流程，主人 QQ 号直接填。

## 数据放在哪

人格、状态和记忆在 `$DSH_HOME/companion/`（默认 `~/.dsh/companion/`）：

```text
soul.md                   人格
config.json               配置（QQ、心跳、模型、记忆开关……；含 AppSecret，权限 0600）
state.json                心情、精力、好感度、今日计数
memories.json             关于你的记忆
embeddings.json           记忆的语义向量索引（可删，下一次检索自动重建；不存原文）
session.json              当前使用的 DSH Session 指针（id/title/nextTurn）
events/YYYY-MM-DD.json    每天的小事
diary/YYYY-MM-DD.md       日记
chat.legacy.jsonl         旧版内部聊天记录（首次迁移后归档，不再写入）
```

对话本体是 **DSH Session**，由 DSH 自己存放在 `~/.dsh/sessions/--…--/<session-id>/`（压缩的 `session.v4.jsonl.zstd`），不要手改。插件只保存“当前用哪个 Session”的指针。

首次启动（或首次绑定后）会把旧 `chat.jsonl` 导入新 Session，然后改名为 `chat.legacy.jsonl`；之后不再写这个文件。`config.json` 含 AppSecret，已 `chmod 600`，不要提交到 Git。

## 会话管理

- **在哪里**：DSH 左侧会话列表，通常挂在 **Ungrouped** 下，标题 `陪伴 · 沈栖（QQ）`。
- **改名**：直接在 DSH 侧边栏重命名。插件只在新会话创建时设一次标题，不会覆盖你的改名。
- **删除 / 归档**：在 DSH 侧边栏操作。插件在下一条消息或下一次概览时检查会话；被删除、归档或 resume 失败时，会自动新建一个会话。旧会话按 DSH 的规则保留或删除。
- **新建**：**设置 → 陪伴 → 设置 → 会话 → 新建陪伴会话**。新建前会先把旧会话压成 1–3 条情景记忆；旧会话仍留在 DSH 里，可以随时回去看。
- **当前会话**：记录在 `~/.dsh/companion/session.json`。插件不会自动接管你在 DSH 里随手新建的空白会话；请用“新建陪伴会话”按钮。
- **只作为记录**：这个 DSH 会话保存 QQ 聊天；在 Web 里打开可以查看/改名/删除，但不要在这里继续聊——Web 输入会走 DSH 默认 Agent，不会同步回 QQ，也不会更新她的心情/记忆。

## 她的一天怎么跑

默认心跳时间 `09:10 / 12:40 / 18:30 / 22:40`。每 30 秒检查一次：

1. 检查静默时段、最小间隔、每日上限；
2. 读取今天已经发生但还没分享的事、当前心情/精力、好感度、最近聊天；
3. 让模型用她的口吻决定：发一条，或者 `[SKIP]`；
4. 发出去的写进 DSH 会话，并把那件事标记为已分享。

她不会连发；被静默/间隔/上限挡下时也不会补发。主动消息和聊天回复共用一条串行队列，避免两条消息同时进来时互相覆盖状态。

另外两个机制：

- **被动窗口降级**：QQ 官方被动回复有约 5 分钟窗口。如果消息在串行队列里等太久（生成慢或前面排着别的消息），回复会自动去掉 `msg_id` 改走主动消息额度，避免白白被平台拒掉。
- **晚间自动日记**：每天 21:00 之后的心跳里，如果当天还没写日记，会自动生成一次（每天最多一篇，幂等）。也可以在设置页手动写/重写。

## 记忆与模型

- 每次回复注入：人格、此刻生活、关系等级、相关记忆、最近 `memory.recentMessages` 条聊天（默认 12）。
- 回复后如果开启「自动记住」，额外调用一次小模型提取关于你的事实/偏好/约定/事件，失败静默跳过。
- **写入门控**：自动提取只接受 `durable=true` 且重要度 ≥ 3 的事；临时状态、一次性动作、寒暄直接丢弃。邮箱、验证码、银行卡、身份证、密码等敏感内容不会自动写入（手动添加不受限）。
- **合并 / 版本**：相似记忆（bigram Jaccard ≥ 0.82）会合并；0.82–0.95 之间视为事实更新，旧版本标记 `superseded` 并保留 `supersedes` 版本链。旧版本不注入、不在列表里显示，记忆页会显示“旧版本 N”。
- **检索权重**：关键词相关度 + 重要度 + 时间衰减 + 使用次数 + 置信度。被检索一次会增加 `accessCount`，下次更容易被想起；长期未确认的记忆自然降权。
- **语义索引**：默认用本机 Ollama `/api/embed` + `nomic-embed-text:latest` 给 active 记忆建 768 维向量索引，存在 `embeddings.json`；检索时“语义相似度 + 关键词 + 权重”一起排序。Ollama 不可用时自动回退关键词检索，失败后冷却 60 秒。
- **设置位置**：设置 → 陪伴 → 设置 → 高级设置 → 语义索引；可开关、改 Ollama 地址/模型；状态会显示已索引条数与维度。
- **遗忘**：`memories.json` 上限 500 条，先淘汰旧版本，再按重要度/确认时间淘汰；UI 显示每条记忆的置信度。
- **轮换摘要**：点“新建陪伴会话”前，先把旧会话最近 60 条聊天压缩成 1–3 条情景记忆（共同经历/约定/长期偏好），写入 `memories.json` 后再切换；摘要失败不会阻止新建。
- **维护页**：低价值自动记忆、可能重复、可能过时、旧版本；支持保留并提升重要度、合并、确认、恢复旧版本、永久删除。
- 模型默认跟随 DSH 当前默认模型（`agentDefaultModel`）；也可以在设置里指定 provider/model 与温度。

## 上下文与长会话

- **模型上下文不会线性增长**：QQ 回复每轮只注入最近 `memory.recentMessages` 条聊天（默认 30）、最多 `memory.maxInjected` 条相关记忆（默认 10），再加人格/生活/关系状态。DSH 会话再长，也不会整份塞进模型。
- **在设置页调窗口**：设置 → 陪伴 → 设置 → 上下文，可改「最近聊天条数」（2–60）和「注入记忆条数」（0–40）。这只影响模型看到的内容，不影响 DSH 会话存储。
- **会长大的是 DSH 会话日志**（以及 Web 里的会话视图）。建议每 **200–300 轮**或 **1–2 个月**点一次“新建陪伴会话”；人格、记忆、心情、好感度都在 `~/.dsh/companion` 里，跨会话保留，连续感不受影响。
- **压缩（compaction）解决的是“模型可见历史”，不是“会话存储”**。它只在让 DSH Agent 自己处理这个会话时才有意义；当前 QQ 回复由插件一次性生成，不经过 Agent 循环，所以不依赖 compaction。
- 如果以后把生成也交给 DSH Agent，应挂 `@deepseek-ai/dsh-compaction-basic` 并设置阈值；那时“轮换会话”和“上下文压缩”可以同时使用：轮换控制存储/视图大小，压缩控制单会话的模型输入。

## 她像人打字

默认开启（`persona.humanize`，可在配置里关掉），让她更像一个人在 QQ 上打字：

- **回复节奏**：不是生成完就发。短消息几秒、长消息十几秒、夜里更慢；拆开的气泡之间也有间隔。同一段话节奏确定，不同的话节奏不同。
- **睡眠窗口**（01:00–08:30）：凌晨发来的消息她不回——在睡觉。消息会记下来，早上醒来后 5–40 分钟内用「刚醒」的口吻补一句。**开了这个她就不是 24/7 有求必应了**。
- **偶发错字**：小概率打错一个词，随后补一条修正（像真人撤回重打）。
- **纯文本**：markdown 记号（`**`、`#`、列表）在发送前剥掉——人不发这些。
- **长度随状态**：累了一个字，心情好话多一点。
- **知识边界**：不看新闻、不追星、不懂数码圈；心算差。问界外的事她会像普通人一样说「不懂」。

## 访客模式

默认关闭（`guests.enabled`）。开启后，主人之外的 QQ 用户也能和她说话——用于让第三方（比如盲测裁判）独立测试：

- **独立记忆**：访客的记忆与主人完全隔离（`memories.json` 里按 owner 命名空间），互不污染、互不可见。
- **独立聊天**：访客对话存 `guests/chat-*.jsonl`，不进主人的 DSH 会话。
- **不动主人状态**：访客聊天不涨好感度、不改心情。
- **限频**：`guests.maxPerDay`（默认 40 条/天/人），超出只回一句「今天说得有点多了」。
- **记忆提取**：默认关闭（`guests.extract`）——访客的对话不值得长期记住，开了也会存进访客自己的命名空间。

裁判的测试对话永远不会污染你和她的关系。测试完直接关掉开关即可。

## 边界

- 她不会自己上网找新闻；“趣事”来自她自己每天的生活事件，不是抓取来的信息流。
- 主动消息依赖 DSH Web Host 一直运行；Host 关掉就不会发。
- 官方 API 只发文本；图片/语音/文件暂不发送，收到图片会以 `[图片/附件]` 占位。
- 官方 OpenID 按 AppID 隔离；换机器人 AppID 后需要重新绑定。
- 插件不把 QQ 回复交给 Agent 循环；回复仍由插件一次性生成，只用一个专用 DSH Session 作为记录。其他 Web 会话不受影响；在陪伴会话里手动发消息会走 DSH 默认 Agent，不会同步回 QQ，也不会更新她的心情/记忆。

## 开发

```sh
cd /home/david/dsh-plugin/companion
node --test test/run.mjs
```

模块：

- `lib/life.js` — 时间投影、每日事件、作息、心情/好感度文字化、数据目录、配置迁移。
- `lib/store.js` — 状态、记忆的持久化与检索；旧 `chat.jsonl` 只在迁移/兜底时读取。
- `lib/mind.js` — 提示词组装、`ctx.llm.stream` 调用、记忆提取、日记。
- `lib/qq-official.js` — QQ 官方 API v2：token、WebSocket 网关、C2C 发送、绑定事件解析。
- `lib/qq.js` — 官方 / OneBot 通道门面。
- `lib/session-store.js` — DSH Session 存储：创建/恢复会话、追加消息、迁移旧聊天、新建会话。
- `lib/embeddings.js` — Ollama embedding 索引：批量向量化、持久化、语义检索、失败回退。
- `lib/engine.js` — 聊天 / 主动消息 / 心跳编排。
- `lib/api.js` — `/dsh-companion/api` 路由与鉴权。
- `index.js` — Host 插件入口与主人绑定。
- `client.js` — 设置页 React 组件（手写模块 bundle）。
